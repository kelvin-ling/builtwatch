# October 17 release

Implemented the ranked review recommendations:

1. Multiple distinct developments per changed source, preserving exact evidence.
2. Complete product identities and aliases; older mismatched candidates are withheld.
3. Offline labeled benchmark with passage precision/recall and CI regression gate.
4. Corrected the live privacy explanation to describe rule matching without Bedrock.
5. Monitoring health panel, expected next check, stale profiles and explicit baselines.
6. Opt-in browser alerts and downloadable review digests. Email requires separate verified
   delivery setup; no email provider, subscription or background push was provisioned.
7. Updated source-filter verification, complete JavaScript syntax checking, GitHub CI and
   current development/deployment instructions.

Additional fixes: the already-loaded demo renders when the session service is unavailable;
interrupted persistence retries against unchanged snapshots; legacy outcomes survive the
matcher upgrade instead of generating duplicate reviews.

Validation: 169 Python and 62 Node tests; 30/30 synthetic benchmark cases (17 expected
passages, zero false positives/negatives); Ruff; syntax; production build; desktop/mobile
browser QA and real digest download. Synthetic results do not establish field accuracy.
Authentication/runtime boundaries were exercised in tests; a signed-in production browser
walkthrough and actual OS-notification delivery were not exercised.

Paid inference stays disabled. Tenant data, identities, service quotas, daily schedule and
public audience are preserved. AWS/hosting/storage costs remain possible.
