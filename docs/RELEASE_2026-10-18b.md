The live status audit found all seven saved apps checked across 21 sources this morning,
with no failed retrievals and USD 0 model usage. Home and public Impact returned 200;

## Changes

- Interrupted additions survive subsequent page edits while any saved app still has
  uncompleted work. A scoped scan cannot consume another app's pending work. Completed
  additions expire on the next substantive edit rather than accumulating forever.
- Cosmetic casing and whitespace edits rebind pending evidence to exact current text.
  Removed passages are not quoted as current evidence. Pure deletions remain outside
  automated candidate matching, as documented in OPERATIONS.md.
- Inline HTML links, emphasis and code retain readable paragraph context. Separate
  paragraphs remain separate, preventing one product from borrowing another's security
  language. Formatting changes from the extractor upgrade do not manufacture additions.
- Backend maps say “Matched app fact” and “components matched.” A matching recorded fact
  is not a confirmed impact. The visual graph and review flow remain available.
- Deployment supports a separate private backup folder for each release, preserving a
  current rollback package without overwriting earlier backups.

The assessment cache uses `rules-v3`. Earlier rule findings retain their evidence-based
development identity and recorded outcomes. No paid provider, subscription, scheduled
job or compute instance is added. Bedrock denial and all zero model ceilings remain.
The first upgraded scan reevaluates existing app/source pairs without model calls;
pending-work checks add bounded storage reads. Normal AWS/Sites infrastructure charges
still apply, and there is no hard total-invoice cap.

## Validation

206 offline Python tests, 79 Node/runtime tests, Ruff, JavaScript syntax and the production
build passed. The 30 labeled synthetic regression cases passed with zero model calls;
they are not a field-accuracy estimate. New regressions cover changing-page and scoped
retries in SQLite and DynamoDB, cosmetic retry edits, extractor migration, linked security
names, exact grounding and isolation between unrelated paragraphs.

The public overview and evidence-to-review dialog were inspected in Chrome. A signed-in
production browser walkthrough was not performed. Authentication and tenant boundaries
are covered by the offline runtime tests and anonymous production checks.

## Next decisions

The strongest next quality investment is an independently labeled corpus of real source
changes, including both missed and irrelevant changes. The synthetic suite cannot prove
real-world precision or recall. More sources or a free semantic model should follow that
measurement, with explicit privacy terms and hard quotas; neither is silently enabled.
