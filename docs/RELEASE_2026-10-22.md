# Workspace response recovery — 22 October 2026

A successful HTTP status with incomplete session/workspace JSON could clear the
private desk or leave it unable to render. The browser now validates the session's
explicit sign-in flag and the private workspace's top-level collection contract
before replacing the current view. It retains the last valid desk on a failed read;
use Refresh to retry. A real signed-out response still opens the local demo.

This is a browser boundary check, not a full nested profile schema. Normal empty
workspaces and empty successful mutation responses remain valid. No mutation is
retried automatically. No AWS/backend, model, schedule, quota, storage or service
configuration changes are included.

Validation: 90 JavaScript and 210 offline Python tests in the published Site;
104 JavaScript and 231 Python tests (one skip) in the current canonical checkout,
plus Ruff, syntax/build checks, zero-model rule evaluation and desktop/mobile
Chrome recovery checks. Browser fixtures cover incomplete reads, explicit sign-out,
valid retry and unknown mutation outcomes without production writes. Actual
owner-authenticated AWS scans were not exercised. The exact published revision
and live verification are recorded in the maintenance release ledger. Roll back the website to saved Sites version 103 if needed; the
backend is unchanged.
